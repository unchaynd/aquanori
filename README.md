# Aquanori: The Users' Code Editor

Aquanori is still under construction, but my hope is that one day it will be a code editor that:
* can run in a terminal or terminal emulator,
* is as powerful as (or maybe even more powerful than) Vim,
* can easily be customized or extended in advanced ways,
* is easy for newcomers to learn,
* is a joy to use, and
* last but not least, is FREE, LIBRE, AND OPEN-SOURCE!!!
